# Architecture

> Generated by codebase-mapper on 2026-09-30

## Overview

This is a static, single-page marketing site for Bharat Bhujal Tech. The page is composed of semantic HTML sections, a single global stylesheet, and a small vanilla JavaScript interaction layer.

## System Diagram

```text
index.html
  ├─ style.css (layout, responsive design, visual system)
  ├─ main.js (menus, video, counters, modals, section interactions)
  └─ assect/* (logos, photos, video, generated hero visuals)
```

## Components

### Marketing page sections
- **Purpose:** Present the company, services, process, projects, FAQs and contact actions.
- **Location:** `index.html`
- **Dependencies:** Font Awesome CDN, Google Fonts CDN, local media assets.

### About showcase
- **Purpose:** Reproduce the supplied Engineering Better Water Solutions composition.
- **Location:** `index.html`, `style.css`, `assect/about-showcase-generated.png`
- **Dependencies:** CSS overlays for responsive metric callouts.

### Interaction layer
- **Purpose:** Mobile navigation, hero video looping, counters, visual switching, modals and form behavior.
- **Location:** `main.js`

## Data Flow

All content is statically authored in HTML. User interactions update classes, media sources and modal DOM nodes in the browser; there is no backend or API data flow in this repository.

| External Service | Type | Purpose |

## Conventions

- **Naming:** Section-scoped kebab-case CSS classes; descriptive asset filenames.
- **Structure:** One HTML entry page, one global stylesheet and one JavaScript entry file.
- **Testing:** Static validation scripts under `scripts/`; browser-level visual verification is recommended for layout changes.
